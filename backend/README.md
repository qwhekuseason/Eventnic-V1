# Eventnic Backend

Node.js + Express + TypeScript backend scaffold.

## Requirements
- Node.js 18+

## Setup
```bash
cd Eventnic/backend
npm install
```

## Run (dev)
```bash
npm run dev
```

## Build
```bash
npm run build
```

## Run (prod)
```bash
npm start
```

## Endpoints
- `GET /health` -> `{ "ok": true }`

## Env
Copy `.env.example` to `.env` and adjust if needed.
